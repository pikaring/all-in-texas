# All in TEXAS － 初心者モード付きテキサスホールデム

ブラウザだけで遊べる軽量なノーリミット・テキサスホールデム。
**初心者モード**を ON にすると、自分の手番ごとに勝率・アウツ・ポットオッズと
「おすすめのアクション」を理由つきで表示し、遊びながら戦略を学べます。

- インストール不要・オフライン動作・外部送信なし
- スマホ縦持ち（幅 430px）を基準にした 1 画面レイアウト
- 自分 + CPU 1〜5 人のシット＆ゴー。CPU は 5 種類の打ち筋からランダム

## 遊び方

- 紹介ページ: <https://pikaring.github.io/all-in-texas/>
- 本体: <https://pikaring.github.io/all-in-texas/app/>（1 ファイル版は `app/standalone.html`）

ローカルでは `app/index.html` を開くだけ。

| ボタン | 内容 |
|---|---|
| 初心者 | 勝率・アウツ・必要勝率・推奨アクションを表示（おすすめのボタンに金枠） |
| 透視 | CPU の手札を表向きにする（答え合わせ用） |
| 速度 | CPU の思考時間 |
| 相手 | CPU の人数（1〜5） |
| ハンド表 | 169 種のスターティングハンドを強さで色分けした表 |

## 初心者モードの計算

- **勝率**: 残っている相手が「これまでの行動から推定されるレンジ」を持つと仮定し、
  残りのカードをランダムに配って最後まで戦わせるモンテカルロ法（1,500 試行）。
  レイズした人は上位 20%、レイズにコールした人は上位 30%、リンプした人は上位 55%、
  ポストフロップでベットした人はさらに 0.7 倍、と絞っていきます。
- **スターティングハンドの順位**: `tools/make_preflop.js` で 169 種それぞれの
  ランダム相手に対する勝率（ヘッズアップ／4 人打ち）を 4 万試行で求め、`app/js/preflop.js` に埋め込み。
- **アウツ**: 次の 1 枚で役のカテゴリが上がる札。ボードだけで役が上がる札（全員共通）は除く。
- **必要勝率**（ポットオッズ）: コール額 ÷（ポット + コール額）。
- **推奨アクション**: プリフロップはポジション別の参加基準（上位 12〜28%）、
  ポストフロップは「勝率 vs 必要勝率」と役の強さで、ベット／コール／チェック／フォールドを決めます。

アイコン（`assets/icon.png`）は `make_icon.py` で生成。夕焼けの砂漠にサボテン、手前に A♠A♥（ポケットエース）。

## 開発

```
app/
  index.html        画面
  css/style.css
  js/cards.js       カード表現と 5〜7 枚の役判定
  js/preflop.js     169 種の勝率表（生成物）
  js/equity.js      モンテカルロ勝率・アウツ
  js/coach.js       初心者モードの解説と推奨
  js/ai.js          CPU の打ち方（5 種の打ち筋）
  js/game.js        ゲーム進行（ブラインド・サイドポット・ショーダウン）
  js/ui.js          描画と操作
  build.js          standalone.html を生成
  tests/run.js      自動テスト
tools/make_preflop.js   勝率表の生成
```

```bash
cd app
node tests/run.js      # 役判定（5 枚全通りの分布）・勝率・サイドポット・CPU 同士の対局
node build.js          # standalone.html を再生成
node ../tools/make_preflop.js   # 勝率表を作り直す（約 15 秒）
```
